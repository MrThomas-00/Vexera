# Voxera

Voxera is a modern gaming-themed landing page built with React and Vite. It presents a futuristic server/community brand with dynamic sections, animated visuals, and a responsive footer.

## Features

- Responsive layout for desktop and mobile
- Animated ambient background effects
- Styled gaming UI and neon color palette
- Quick navigation routes for Home, Store, Blog, Wiki, and Download
- Footer with social links, server status, and copyable IP
- Fast Vite build for production deployment

## Tech Stack

- React
- Vite
- React Router
- Tailwind CSS
- React Icons

## Run locally

```bash
npm install
npm run dev -- --host 0.0.0.0
```

## Build for production

```bash
npm run build
```
